# J floor website

Independent SolidJS / Vite website. Built from the approved narrative and brand specifications; no landing-page layout or component code is reused. Self-hosted assets, SCSS modules, and prerendered HTML. The member application and landing-page package are unchanged.

Run `bun install` from the repository root, then `bun run --filter @j-os/website dev` (port 5174). Run package `test`, `lint`, `typecheck`, `format:check`, and `build` scripts before delivery.

Cloudflare Pages: root directory `apps/website`, build command `bun run build`, output `dist`. The generated top-level `404.html` deliberately disables Pages' SPA fallback. No deployment or domain change is made by this package.

Edit `src/content.ts` for metrics, supporters, photo slots, and events; `src/site.ts` for canonical destinations. Event dates use Europe/Zurich. Status and ordering are evaluated at build time; rebuild to refresh the static site. All initial events are marked as samples and use example.com links. Community photographs use the supplied group portrait, shared workspace, and black-and-white lounge, with captions overlaid on each image. Delivery WebP assets live under `public/assets/community`.

The homepage hero fills the viewport and centers the opening elevator mark. Its navbar is hidden on initial arrival, reveals on the first scroll, and remains fixed and visible afterward, including when scrolling back to the top. Inner pages and direct section links retain immediately available navigation. Its introduction automatically plays four word-by-word statements and resolves into the J floor wordmark. Scrolling reveals the navbar and invitations independently of the ongoing text animation. “Build in Zurich. Capture the world.” appears once the wordmark resolves; the buttons have their own reserved space beneath the animated sentence. Without scrolling, the invitations appear automatically after the story. Native scrolling moves directly into Community, with no forced wait for the animation. Reduced motion and no JavaScript keep the identity and invitations accessible in ordinary document flow. Keyboard users can skip directly to the invitations.

There is no separate train hero. The supplied community video loops silently behind the intro graphic and final invitations, with a charcoal overlay and a pause/play control. The original file is preserved; the self-hosted delivery copy has no audio track and supports progressive playback. Reduced-motion and no-JavaScript visits show a matching poster without requesting video bytes. Playback pauses offscreen or in hidden tabs. Before production, replace or remove demo events and verify photograph permissions and context.

Partner recognition uses the supplied v17 catalogue: seven sponsors (including Alfred), five in-kind contributors, and 31 event partners. Edit `src/partners.ts` for the roster and logo presentation metadata. Delivery logos are self-hosted under `public/assets/partners`; originals remain in the supplied collection. Raster display variants use white artwork on transparent PNG backgrounds; vector artwork is rendered white with a CSS filter. Swisscom Ventures is retained without a separate Swisscom entry. The AWS delivery SVG removes embedded animation state that hid and displaced its wordmark; its paths and colors are preserved.

The partner section uses the selected grouped wall: larger sponsor logos, a tightly wrapped event-partner cloud, and all partners visible without interaction. Event marks use cropped transparent artwork and individual optical dimensions to balance visible size. Previous layout-review URL parameters are ignored.
